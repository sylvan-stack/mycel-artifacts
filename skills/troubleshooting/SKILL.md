---
name: troubleshooting
description: >-
  Activate when the user explicitly asks to troubleshoot a difficult
  implementation or bug-fix issue, asks to continue an existing named
  troubleshooting investigation, or asks to wrap up or hand off an active
  troubleshooting session so another Chat Session can resume from durable
  state. Example prompts: "Troubleshoot why Gmail sync misses the full email
  thread", "Let's continue Emails Sync Troubleshooting", and "Wrap this
  troubleshooting session up and give me a continuation prompt". Handoff
  phrases include "wrap it up", "wrap this session", "hand off this session",
  and "finalize session" when troubleshooting is active. Do NOT activate for
  ordinary implementation or bug fixing that is making normal progress, a
  generic request to summarize or end a non-troubleshooting conversation, a
  quick how/where/why code question (code-research), open-ended context
  gathering (deep-research), or implementation planning (implementation-plan).
