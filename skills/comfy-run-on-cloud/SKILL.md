---
name: comfy-run-on-cloud
description: >-
  Get one workflow from the local ComfyUI running on Comfy Cloud: check it
  against Cloud, use an existing build or a node swap where Cloud lacks
  something, run one real job, save it to the Cloud workspace and return its
  link. Examples: "I clicked Run on Cloud in ComfyUI" and "Put this workflow on
  Comfy Cloud"; in Codex use $comfy-run-on-cloud with the same words. NOT for
  packaging a whole environment (comfy-build) or a serverless endpoint
  (comfy-deploy).
---

task.
