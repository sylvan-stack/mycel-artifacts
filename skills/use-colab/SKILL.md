  every explanation in that work is pitched at the owner's experience in the

  kept current. Activate ONLY when the owner's message contains the exact
  phrase "(use colab)", anywhere in it, or calls /use-colab (in Codex
  $use-colab). Example prompts: "(use colab) why does this test hang?" and
  "Review this migration (use colab)". NOT for a message without that
  exact phrase, however much it asks to learn or explain; NOT for
  /colab "prompt", the learning exchange itself (the skill colab).
