---
name: pr-deep-review
description: >-
  Run or continue a long, evidence-backed review of a large pull request from
  its state file: find further issues, review new commits, verify the
  author's fixes, weigh the author's replies and objections, and queue
  verified findings with a drafted comment and file:line for the human
  reviewer. Commands: next, commits, verify, replies, check, summary, status,
  stint. A run can be bounded by a named stint or by explicit limits on
  findings, time, tokens and coverage. Example prompts: "Continue the review
  of Euro-Office/core#116, overnight stint", "Review the new commits on PR
  116", "Did the author fix F3?", "The author says F5 is not a bug, check
  their reply" and "Let's define a new stint for short runs". Never
  posts to the pull request. NOT for a single pass over a small diff (the
  provider's ordinary code review), a how/where/why question about the code
  (code-research), or open-ended context gathering (deep-research).
