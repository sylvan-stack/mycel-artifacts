name: arbol-chat-prepared-folder
description: >-
  Activate in an Arbol chat (the environment has ARBOL_ROOT and ARBOL_CHAT,
  and the working folder is under ~/repos/sylvan-stack/readonly/) before the
  first change to a file in a repository, and at each later message of that
  chat before changing a file: book an Environment, find the one the chat
  booked, change files only there on a branch of the chat's own, and return
  and release the folder when the work is merged. Example prompts, sent in an
  Arbol chat: "Fix the failing test in arbol-trunk", "Rename this option and
  commit it", "Which folder did this chat book?" and "Release this chat's
  Environment". NOT for a chat that only reads and answers, for a change
  only to a corpus in ~/Artifacts/, which stays on main, or for an agent
  outside an Arbol chat, such as one taking, working or finishing a Beat (the
  guide Working in Sagas).
---
