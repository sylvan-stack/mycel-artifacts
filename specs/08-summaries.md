# MYC-8 · Repository summary-tree retirement

## Purpose and scope

The owner retired RAPTOR across Sylvan Stack on 19 November 2026. Repository search uses original indexed text and the ordinary code overview. Narrator remains a standalone tool under [MYC-22](22-narrator-summary-quality.md) and [MYC-23](23-narrator-label-generation.md).

## Behaviour and interface

Remove the `mycel summaries` command and its background generation paths. Quiet-period maintenance still ingests and embeds pending on-disk document sections through `mycel maintain --repo <name>` after 15 minutes of unchanged input. Its existing retry, input observation and scope controls still apply. New settings have no summary configuration. Existing `[summaries]` tables are accepted as inert compatibility data.

A current index has no searchable or readable repository Summary Nodes. Existing rows, evidence and activity records may remain in their original store format. The active catalog omits those nodes and Detection leaves their historical marks alone. Removal of a repository still owns all its store data. The maintained Seqoya design provides embedding and search controls.
